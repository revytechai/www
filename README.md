# REVYTECH AI

REVYTECH platform tooling, services and the catalogues behind them.

This repository publishes the organisation's repository index to
**revytechinc.ai** through GitHub Pages.

- `repos.json` — the index, regenerated by `.github/workflows/pages.yml` on a
  schedule and on every push.
- `index.html` / `site.css` — the page itself.

Cloudflare remains authoritative for DNS and TLS termination in front of it.
